라운드 대기 중

선을 몇 개까지만 그릴 수 있다면?

한 사람이 제시어를 보고 정해진 개수의 선으로만 그림을 그리면, 나머지 친구들이 무엇인지 맞혀요. 다 그리고 나면 무엇을 남기고 무엇을 지웠는지 함께 이야기해 봅니다.

진행 방법

1출제자 한 명이 제시어를 확인해요. (다른 친구들은 못 보게!)
2정해진 선 개수 안에서만 칠판에 그림을 그려요.
3출제자 번호, 정답자 번호를 순서대로 눌러요. 출제자는 2점, 맞힌 사람은 1점을 얻어요.

라운드 설정

모든 제시어를 다 사용했어요! 다시 시작하면 처음부터 섞어서 진행해요.

출제자만 확인하세요

다른 친구들은 화면에서 눈을 떼주세요. 출제자는 화면 왼쪽 아래 작은 확인 칸을 손이나 책으로 가린 채 길게 눌러야만 제시어가 보여요. 손을 떼면 바로 다시 가려집니다.

📌 확인 칸이 화면 구석에 작게 있어요 — 몸으로 가리고 혼자만 볼 수 있게 확인해 주세요.

① 출제자 번호를 눌러주세요

번호를 다 누르면 점수가 반영되고 곧바로 다음 라운드로 넘어가요.

점수판

1번부터 27번까지 번호 순서예요. 출제자는 2점, 정답을 맞힌 사람은 1점씩 쌓여요.

같은 '학생', 하지만 다른 추상화

같은 대상이라도 프로그램의 목적이 다르면, 필요한 정보(속성)도 달라져요. 아래 두 프로그램 중 하나를 눌러서 어떤 정보가 필요한지 살펴보세요.

두 버튼 중 하나를 눌러보세요.

이름·학년·반처럼 '누구인지 확인하는 정보'는 목적과 상관없이 거의 항상 필요해요. 반대로 좋아하는 색깔·연예인·취미·전화번호는 두 프로그램 모두에 필요 없죠 — 목적이 무엇이든 원래부터 불필요한 정보도 있다는 뜻이에요.

오늘 배운 것: 추상화란?

어떤 대상을 표현할 때, 목적에 맞는 핵심적인 특징만 남기고 나머지는 과감히 생략하는 것 — 이것이 추상화(Abstraction)예요.

🖍️ 오늘의 그림 게임

선 5개로 고양이를 그릴 때, 세모난 귀와 수염만 그려도 통했어요. 털 무늬나 눈동자 색 같은 세부사항은 몰라도 알아보는 데 문제없었죠.

🚇 지하철 노선도

실제 거리, 건물, 도로 모양은 다 지우고 '어느 역이 어느 역과 연결되는지'만 남긴 지도예요. 그래도 길 찾는 데는 충분해요.

💻 프로그래밍

'학생' 정보를 성적 프로그램에 담을 때는 이름·학년·반·점수만 남겨요. 함수도 마찬가지예요 — 사용하는 사람은 복잡한 내부 코드를 몰라도 '무엇을 넣으면 무엇이 나오는지'만 알면 충분하죠.

추상화는 '적게 아는 것'이 아니라, 목적에 맞게 골라내는 능력이에요.
