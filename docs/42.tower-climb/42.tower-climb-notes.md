## 3. 규칙 엔진 클래스

| 클래스 | 책임 |
|---|---|
| `ClimbBalance` | 모든 수치(읽기 전용 상수) |
| `PlatformPiece` | 발판 한 개(바닥 모양: 원 또는 Y축으로 돌린 상자, 윗면 높이, 경사). 자식 `StaticPlatform`·`NarrowPlatform`·`SlopePlatform`·`HubIsland`·`StageRest`·`JumpPad`·`LaunchCannon`·`GrabHold` 가 `stand()`(위에 섰을 때)·`takeJump()`(점프 눌렀을 때)만 바꾼다 |
| `ClimbCollisionWorld` | 4m 격자에 발판을 넣고 근처만 찾기, 카메라용 광선 검사(`rayReach`) |
| `ClimbGrabSystem` · `ClimbGrabSpot` | 잡을 곳 찾기(`find`), 위 손잡이(`above`), 옆 손잡이(`beside`) |
| `ClimbTimeScale` | 슬로 배율·게이지 |
| `StageProgress` | 클리어한 스테이지, 포탈 열림 계산(저장은 화면 쪽 `ClimbRecords`) |
| `TowerLevel` · `TowerStage` | 레벨 데이터 → 발판 객체(`PIECE_KINDS` 표로 종류 → 클래스) |
| `ClimbCharacterBody` | 캐릭터 상태(위치는 **발 높이** 기준) |
| `FallReturnWatcher` | 허브 추락(6m 이상 떨어져 허브에 닿음)·바깥 추락(-20m) |
| `ClimbRules` | 한 판. `steer`·`pressJump`·`pressGrab`·`holdSlow` 로 입력을 넣고 `advance(실제 초)` 가 이벤트 목록을 돌려준다 |

- 고정 간격 1/120초. `advance` 가 실제 시간 × 슬로 배율을 모아 틱 단위로만 진행하므로 슬로를 써도 궤적이 같다(단위 검사로 확인). 화면은 `body.prevX…` 와 `rules.blend` 로 보간한다.
- 캐릭터는 세운 원기둥(반지름 0.4, 키 2.0)으로 계산한다. **서 있는지는 중심점이 발판 바닥 모양 안에 있는지**로 정한다(가장자리에서는 코요테 시간 0.12초가 돕는다). 옆면은 반지름만큼 밀어낸다. 0.35m 이하 턱은 그냥 올라선다.
- 잡기 범위: 잡을 곳 높이가 발에서 1.2~2.6m, 수평 1.0m 안. 매달리면 발이 잡은 곳보다 2.0m 아래. 모서리는 0.4초 뒤 자동으로 올라타고, 손잡이는 `Space` 로 위 손잡이(높이 차 0.2~1.6m, 수평 1.3m 안)로 옮긴다. 위에 없으면 손을 놓으며 점프한다.
- 발사대: 힘 p(0.6~1) → 위 속도 `27 × (0.7 + 0.3p)`, 앞 속도 `6.5 + (1-p) × 6.25`. 100% 는 +12m·앞 8.02m. 발사 뒤 8m 이상 높은 곳에 서거나 잡으면 성공으로 센다.
- 최고 높이(`rules.peak`)는 **서 있거나 매달린 높이**만 센다(발사·점프 중 높이는 안 셈).
- 스테이지 1 시간(`stageOneTime`)은 첫 입력부터 30m 쉼터까지 실제 시간, 포탈을 쓴 판은 기록하지 않는다.

## 4. 스테이지 1 배치 (`TowerStageOneLayout`)

가운데 큰 나무 줄기(반지름 3m, 높이 29.5m)를 돌며 오른다. 각도 a·반지름 ρ 로 놓는다(x = ρ·sin a, z = ρ·cos a).

| 높이 | 발판 | 내용 |
|---|---|---|
| 0 | `hub` | 반지름 22m 섬. 시작 지점 (0, 10), 포탈 6개는 ρ 15, a -50°~50° |
| 1~8.4 | `t1`~`t8` | 연속 점프 3회 → 좁은 통나무 `t4` → 쉼터 `t5` → 첫 모서리 잡기 `t6`(2.4m 위) → 쉼터 `t8` |
| 8.4 → 12 | `pad` → `mid` | 작은 점프대, 12m 쉼터(5×5) |
| 12 → 26.5 쉬운 길 | `e1`~`e28`, `join` | 0.5m 씩 오르는 바깥 고리(ρ 7), 5번째마다 쉼터 |
| 잡기 오르막 | `n0`, `h1`~`h4`, `n1`, `ramp` | 줄기의 손잡이 4개(간격 1.0m) → 경사 → `e15` 쉼터로 합류(쉬운 길 14개를 건너뜀) |
| 발사대 길 | `hard1`, `hard2`, `cannon`, `target` | 폭 0.7m 통나무 2개 → 최대 거리의 86% 점프 → 발사대(14m) → 26m 의 3×3 발판 → `e27` 로 합류 |
| 26.5 → 30 | `u1`~`u3`, `rest2` | 줄기 꼭대기 쉼터(반지름 4.2m) = 스테이지 2 시작점 |

봇 완주(실수 없음, 슬로 없음): 쉬운 길 31초, 잡기 오르막 24초, 발사대 18초. 사람은 2~3배로 본다. 사양서 목표(숙련 80초)보다 짧으면 `EASY_RISE` 를 줄이고 `EASY_COUNT` 를 늘린다.
발사대 힘 60~80% 는 목표에 못 미쳐 허브까지 떨어지지만 `E` 로 목표 발판 모서리를 잡으면 산다. 90% 이상은 그냥 착지한다.

## 5. 검사

```
npx tsc -p .
node tools/climb-unit.js      # 수치·잡기·점프대·발사대·슬로·포탈·추락 규칙
node tools/climb-reach.js -v  # 길마다 이웃 발판 분류와 점프 비율, 봇 완주, 발사대 힘별 결과, 갇힘
node tools/climb-sim.js 5000  # 실수하는 봇 5천 판(약 4분)
```
세 가지가 모두 통과해야 푸시한다. 발판을 옮기면 `climb-reach.js -v` 의 간격·비율 줄을 먼저 본다.
