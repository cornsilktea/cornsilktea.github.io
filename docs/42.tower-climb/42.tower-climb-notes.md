## 3. 규칙 엔진 클래스

| 클래스 | 책임 |
|---|---|
| `ClimbBalance` | 모든 수치(읽기 전용 상수) |
| `PlatformPiece` | 발판 한 개(바닥 모양: 원 또는 Y축으로 돌린 상자, 윗면 높이, 경사). 자식 `StaticPlatform`·`NarrowPlatform`·`SlopePlatform`·`HubIsland`·`StageRest`·`JumpPad`·`LaunchCannon`·`GrabHold` 가 `stand()`(위에 섰을 때)·`takeJump()`(점프 눌렀을 때)만 바꾼다 |
| `ClimbCollisionWorld` | 4m 격자에 발판을 넣고 근처만 찾기, 카메라용 광선 검사(`rayReach`) |
| `ClimbGrabSystem` · `ClimbGrabSpot` | 잡을 곳 찾기(`find`), 위 손잡이(`above`), 옆 손잡이(`beside`) |
| `ClimbTimeScale` | 슬로 배율(게이지 없음) |
| `StageProgress` | 클리어한 스테이지, 포탈 열림 계산(저장은 화면 쪽 `ClimbRecords`) |
| `TowerLevel` · `TowerStage` | 레벨 데이터 → 발판 객체(`PIECE_KINDS` 표로 종류 → 클래스) |
| `ClimbCharacterBody` | 캐릭터 상태(위치는 **발 높이** 기준) |
| `FallReturnWatcher` | 허브 추락(6m 이상 떨어져 허브에 닿음)·바깥 추락(-20m) |
| `ClimbRules` | 한 판. `steer`·`pressJump`·`pressGrab`·`holdSlow` 로 입력을 넣고 `advance(실제 초)` 가 이벤트 목록을 돌려준다 |

- 고정 간격 1/120초. `advance` 가 실제 시간 × 슬로 배율을 모아 틱 단위로만 진행하므로 슬로를 써도 궤적이 같다(단위 검사로 확인). 화면은 `body.prevX…` 와 `rules.blend` 로 보간한다.
- 캐릭터는 세운 원기둥(반지름 0.4, 키 2.0)으로 계산한다. **서 있는지는 중심점이 발판 바닥 모양 안에 있는지**로 정한다(가장자리에서는 코요테 시간 0.12초가 돕는다). 옆면은 반지름만큼 밀어낸다. 0.35m 이하 턱은 그냥 올라선다.
- **잡기는 완전 자동**(2026-11-17 선생님 결정, `E`·잡기 버튼 없음): 공중에 있을 때 매 틱 이동이 끝난 뒤 `canAutoGrab` 이 잡을 곳을 찾는다. 서 있을 때는 잡지 않는다. 올라가는 중에는 지금 속도로 닿는 꼭대기(+`CLEAR_MARGIN` 0.15m)보다 높은 곳만 잡아 점프로 넘을 수 있는 발판은 그냥 올라선다. 벽 반대쪽으로 움직이는 중(`MANTLE_PUSH` 이상)이면 잡지 않는다. 손을 놓은 곳(`letGo`)은 땅에 닿을 때까지 다시 잡지 않는다. 매달린 채 벽 반대쪽(S·조이스틱 아래)으로 당기면 손을 놓는다.
- 잡기 범위(공중): 잡을 곳 높이가 발에서 0.9~2.8m, 수평 1.4m 안(`findFor`). `find`(서 있을 때 1.2~2.6m·1.0m)는 검사 도구만 쓴다. 공중 잡기는 캐릭터가 보는 방향(벽 바깥 방향과 각 cos ≥ 0.4) 안의 가장 가까운 곳을 먼저 잡고, 없으면 다른 방향의 가장 가까운 곳을 잡는다. 잡을 때 0.2초 `GRAB_SWING` 동안 화면이 위치를 따라가며 몸을 천천히 돌린다(`SWING_TURN_RATE`), 그동안 누른 점프는 남겨 둔다. 매달리면 발이 잡은 곳보다 2.0m 아래. 모서리는 **저절로 올라가지 않는다**(2026-11-17 선생님 요청): 매달리고 0.2초 지난 뒤 점프를 누르거나 벽 쪽으로 밀면(`MANTLE_PUSH`, W·조이스틱 위) 기어오른다(`climbUp` 상태 0.5초, `ClimbUpPath` 가 앞 60% 동안 윗면 +0.15m 까지 끌어올리고 나머지 동안 앞으로 넘어가 선다. 화면은 `Jump_Idle` → `Jump_Land` 와 앞으로 숙이기). 그 동안은 입력을 받지 않는다, 손잡이는 `Space` 로 위 손잡이(높이 차 0.2~1.6m, 수평 1.3m 안)로 옮긴다. 위에 없으면 손을 놓으며 점프한다.
- 발사대: 힘 p(0.6~1) → 위 속도 `27 × (0.7 + 0.3p)`, 앞 속도 `6.5 + (1-p) × 6.25`. 100% 는 +12m·앞 8.02m. 발사 뒤 8m 이상 높은 곳에 서거나 잡으면 성공으로 센다.
- 최고 높이(`rules.peak`)는 **서 있거나 매달린 높이**만 센다(발사·점프 중 높이는 안 셈).
- 스테이지 1 시간(`stageOneTime`)은 첫 입력부터 30m 쉼터까지 실제 시간, 포탈을 쓴 판은 기록하지 않는다.

| 높이 | 발판 | 내용 |
|---|---|---|
| 0 | `hub` | 반지름 22m 섬. 시작 지점 (0, 10), 포탈 6개는 ρ 15, a -50°~50° |
| 1~8.4 | `t1`~`t8` | (발판은 줄기·쉼터·손잡이·섬만 원, 나머지는 상자) 연속 점프 3회 → 좁은 통나무 `t4` → 쉼터 `t5` → 첫 모서리 잡기 `t6`(2.4m 위) → 쉼터 `t8` |
| 8.4 → 12 | `pad` → `mid` | 작은 점프대, 12m 쉼터(5×5) |
| 12 → 26.5 쉬운 길 | `c1`~`c13`, `join` | (2026-11-17 바꿈: 짧은 발판 28개 대신) 3.4m 큰 블록이 바깥 고리(ρ 7)를 한 바퀴 반 돈다. `CLIMB_PATH` 표 = [각도, 윗면]. 2.2~2.6m 높은 블록(벽, 점프하며 모서리 잡기)과 0.6~0.9m 간격의 평평한 점프가 섞임. 마지막 `join`(ρ 6.3) → `rest2` 는 3.5m 기어오르기 |

봇 완주(실수 없음, 슬로 없음, 2026-11-17 배치): 쉬운 길 22.9초, 잡기 오르막 16.9초, 발사대 15.7초. 사람은 2~3배로 본다(기어오르기마다 매달림 → 오르기 입력이 필요). 길이를 늘리려면 `CLIMB_PATH` 에 [각도, 윗면] 을 더하고 `JOIN_DEG` 를 옮긴다. 발사대 길이 잡기 오르막보다 빨라야 한다(`climb-reach.js` 가 확인).
발사대 힘 60~80% 는 목표에 못 미쳐 목표 발판 모서리를 저절로 잡아 산다. 90% 이상은 그냥 착지한다.

## 4-2. 스테이지 2 배치 (`TowerStageTwoLayout`, 2026-11-17 둘째 판)

30m 쉼터(`rest2`) → 60m 쉼터(`rest3`, 스테이지 3 시작점). 가운데 돌기둥 탑 `tower2`(반지름 3m)는 **34m 부터** 시작한다 — 30m 쉼터 한가운데(포탈로 도착하는 자리) 위를 비워 둔다(`climb-reach.js` 가 "시작 쉼터 가운데 위가 비어 있음"으로 확인).

**선생님 요청(2026-11-17)**: 첫 판(ρ 7 고리의 돌 블록 + 손잡이)이 탑에 너무 붙어 돌고 점프·매달리기뿐이라 다시 짰다. 폐허 섬의 집도 발판으로 쓰고, 더 넓게 돌고, 여러 에셋을 발판으로 쓰고, 더 멀리 뛰게 했다. 손잡이 오르막은 없앴다.

- **세 길은 쉼터에서 서로 다른 방향의 성벽 다리(바큇살)로 출발**한다: 쉬운 길 0°, 지붕 길 140°, 발사대 길 -88°. 다리 윗면은 30m 라 쉼터에서 걸어 나간다.
- **발판 종류(`TowerPropShapes.SHAPES`)**: 모델 치수표 하나를 배치(충돌 크기)와 그림(모델 맞추기)이 같이 쓴다. `ClimbLayoutPen.prop(id, kind, look, x, z, 윗면, 배율, yaw)` 가 크기를 정한다.

| 쉬운 길(비율 한계 0.75) | `vw1` → `vi1` … `vt6` → `vw4` | ρ 14~16 에서 한 바퀴. 망루 4곳은 1m 떨어져 점프하며 3.6m 모서리 잡기, 떠 있는 상자·통은 2.5~3.5m 점프(최대 거리의 63~74%), 육각 섬 위 점프대 2곳(+3.3m). `vi2` 섬에서는 통 → 상자 → **집 용마루**로 올라 2.98m 점프. 마지막은 `vt5` 망루 → `vhB` 집 용마루 → `vt6` 망루(60m, ρ 11.5) → 성벽 다리 `vw4` 로 걸어 `rest3` |

| 발사대(0.9) | `xw1` → `xb1`(통) → `xc1`(상자) → `xcan`(33.5m) → `xtarget`(45.5m) → `vb2`… | 안쪽 고리 ρ 11.4 에서 통·상자를 최대 거리의 79% 로 건너 발사대. 발사대 위치는 목표(`vb2` 안쪽 1.2m)까지 날아가는 거리 8.02m 가 되는 자리로 계산한다. 목표 → `vb2` 2.3m 모서리 잡기 |

- 그림: 탑 `tower` = `dungeon/column` 을 4m 씩 쌓음, 발사대 목표는 `slab`(Block Bits 돌). 배경 폐허 섬 6개(돌 받침 + 교회·망루·무너진 집)는 발판으로 착각하지 않게 ρ 33~36 으로 물렸다.
- 봇 완주(2026-11-17 둘째 판): 쉬운 길 21.4초, 지붕 길 17.3초, 발사대 14.1초. 시뮬레이션(3천 판) 도착 쉬운 길 94~95%, 지붕 길 95~99%, 발사대 96~98%. 실패는 점프를 놓쳐 아래로 떨어진 판(봇은 다시 길을 찾지 못함).
- 집 용마루에서 떨어지면 지붕을 미끄러져 그 집 섬에 내려선다. 섬에서 몸통 옆으로 붙어 점프하면 용마루를 저절로 잡고 다시 오를 수 있다.

## 4-3. 스테이지 3 배치 (`TowerStageThreeLayout`, 2026-11-17)

60m 쉼터(`rest3`) → 90m 쉼터(`rest4`, `startOf: 4`). 탑 `tower3` 은 64m 부터(60m 쉼터 가운데 위를 비움). 조각 이름 머리글자: 쉬운 길 `d`, 기둥 길 `l`, 연쇄 발사대 `c`.

**선생님 요청(2026-11-17)**: 스테이지 2보다 거리가 멀고 어렵게. 점프 비율 한계를 쉬운 길 0.75 → **0.85**, 둘째 길 0.8 → **0.9**, 발사대 길 0.9 → **0.93** 으로 올렸다. 모서리 잡기 간격도 1.0~1.2m → **1.3~1.5m**(한계 1.6m).

- 연쇄 발사대: 발사대 사이 거리는 날아가는 거리 8.02m 와 같은 현(ρ 11 위에서 42.8°)으로 놓는다(`ClimbRingBuilder.cannonAt`, 다음 발사대 쪽을 보게 돌림). 발사대는 모서리를 잡을 수 없어 `cc1` 을 60~80% 로 쏘면 `cc2` 에 못 미쳐 스테이지 2(47m)까지 떨어진다. `cc2` 를 60~80% 로 쏘면 `ctarget` 모서리를 잡는다. `climb-reach.js` 가 길 안의 **모든 발사대**를 힘별로 확인한다.
- 세 길의 바큇살·고리·도착 다리 각도는 서로, 그리고 스테이지 2 도착(-3°, `vt6`·`vw4`)과 겹치지 않게 골랐다. 겹침은 `.claude/s3overlap.js`(커밋 안 함, 수평 0.6m 안·세로 틈 3.2m 미만 조각 쌍)로 봤다.
- 배경: ρ 33~36 에 던전 섬 6개(바닥 타일 + 벽 + 기둥 둘 + 횃불 + 돌무더기, `TowerLevelBuilder.DUNGEON_ISLANDS`).
- 봇 완주: 쉬운 길 22.0초, 기둥 길 19.6초, 연쇄 발사대 10.5초. 시뮬레이션(3천 판) 도착: 쉬운 길 88~97%, 기둥 길 86~98%, 연쇄 발사대 94~99%.

- **그림**: 발판은 Block Bits(`assets/kaykit/blocks/` 풀·흙·돌·나무·노란 줄무늬·빨강), 줄기와 쉼터는 `dungeon/barrel_large`, 포탈은 `dungeon/wall_doorway`, 허브 장식은 `forest/`. 발판 모양이 충돌 상자와 정확히 같도록 블록을 크기에 맞춰 늘린다(바위 모델은 윗면이 둥글어 쓰지 않음). 섬 바닥만 직접 만든 원기둥이다.

- 세계·우리 반 기록(`towerclimb`, 정수 m, 규칙 상한 200)은 추락·클리어·시작 화면으로 나갈 때 `WR.prompt` 로 올린다.
- 카운트다운 첫 프레임에 포탈을 컬러·흑백으로 한 번씩 그려 둔다(`ClimbWorldView.warmUp`).
- **화면 확인**: 등록 전이라 `?c=test` 도 잠겨 있다. `node tools/climb-test-page.js` → `http://localhost:포트/.claude/climb-test.html`. 콘솔의 `__game` 으로 `__game.rules.body.place(x, y, z)` 처럼 옮겨 볼 수 있다(다른 상태에서 옮기면 `body.mode = "free"` 도 같이).
