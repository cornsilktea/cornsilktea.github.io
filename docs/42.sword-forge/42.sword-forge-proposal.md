# 42번 검 강화하기 (대장간) — 기본 제안서 (v0.1, 2026-11-16)

검을 **강화해서 +20까지** 키우는 개인전 게임. "성공하면 짜릿하고, 실패하면 아깝지만 한 번 더"가 핵심이다.
선생님이 읽고 고친 뒤 확정한다. 확정 전에는 코드를 만들지 않는다.

**표식**: **【조사】** 인터넷·장르 공통 규칙에서 가져온 것 / **【제안】** 이 게임에서 새로 넣는 도파민 요소 / **【확인】** 선생님이 정할 값(기본값 ★). 수치는 모두 **초기값**이며 시뮬레이션(7절)으로 분포를 본 뒤 확정한다.

---

## 1. 조사 요약 — 검 강화 게임의 공통 규칙 【조사】

검색으로 "검 키우기" 한 게임의 공식 확률표는 찾지 못했다. 대신 강화형 게임(검은사막·메이플스토리·라그나로크·아이온2 등 장비 강화)과 모바일 "검 키우기·강화 키우기"류의 **공통 구조**를 정리했다.

| 요소 | 공통 규칙 |
|---|---|
| 기본 루프 | 골드를 내고 **강화** 버튼 → 확률 판정 → 성공하면 +1, 실패하면 벌칙 → 필요하면 **판매**해 골드를 번다 |
| 확률 | 낮은 단계는 100%에서 시작해 **단계가 오를수록 낮아진다**(초반 100·92·85·78…) |
| 실패 벌칙 3종 | ① 재료(골드)만 잃고 유지 ② **단계 하락** ③ **파괴**. 단계 구간마다 벌칙이 다르게 설정된다(안전 구간 → 위험 구간) |
| 보호 아이템 | 파괴·하락을 막는 **방어권/보호석**, 확률을 올리는 **축복 주문서** (대신 비싸거나 구간 제한이 있다) |
| 실패 누적 보너스 | 실패할수록 다음 성공 확률이 오르는 **천장(피티)** 장치가 흔하다 |
| 판매 | 단계가 높을수록 **판매가가 기하급수적으로** 오른다 → "지금 팔까, 더 갈까" 갈등이 재미의 중심 |

출처(참고): [강화 3단계 구조 설명](https://gamewith.ai/aion2/en/enhancement-simulator) · [강화 실패 시 하락/파괴·보호석 사례](https://elwiki.net/w/Enhancement) · [실패 누적 시 확률 보정 사례](https://irowiki.org/wiki/Refine) · [검은사막 실패 스택](https://grumpygreen.cricket/bdo-failstack-chart/)

**결론**: 규칙은 단순하다 — *확률 + 벌칙 + 보호 + 판매*. 재미는 규칙이 아니라 **연출과 선택의 긴장**에서 나온다. 그래서 이 제안서의 무게는 3·4절(도파민 설계)에 둔다.

## 2. 기본 규칙 (초기값)

| 항목 | 값 |
|---|---|
| 목표 | 검을 **+20** 까지 강화 (이후 "전설 검 해금"과 다음 검 종류) |
| 시작 | 나무 검 +0, 골드 500 |
| 강화 비용 | `30 × 1.45^단계` 골드 (올림) 【확인】 |
| 판매가 | `20 × 1.7^단계` 골드. 판매하면 +0 새 검(같은 종류)을 받는다 |
| 파괴 시 | 검이 부서지고 **검 조각**을 받는다(3.4절). +0 나무 검으로 다시 시작 |

### 2.1 단계별 확률과 실패 벌칙 【확인】

| 구간 | 성공 확률(+n → +n+1) | 실패하면 |
|---|---|---|
| +0~+5 **안전** | 100·95·90·85·80·75 % | 그대로 유지 |
| +6~+11 **위험** | 70·65·60·55·50·45 % | **−1 단계** |
| +12~+15 **파괴** | 40·35·30·25 % | 실패 중 **20%** 는 파괴, 나머지는 −1 |
| +16~+18 **지옥** | 20·15·10 % | 실패 중 **35%** 는 파괴, 나머지는 −1 |
| +19 **마지막** (+19→+20) | 5 % | 실패 중 **50%** 는 파괴, 나머지는 −1 |

(최종 표는 시뮬레이션 뒤 확정.)

### 2.2 보조 아이템 【조사 → 제안】
| 아이템 | 효과 | 얻는 법 |
|---|---|---|
| **방어권** | 이번 강화 한 번, **파괴·하락을 막음**(실패해도 유지) | 상점(골드) 또는 연속 실패 보상 |
| **축복 주문서** | 이번 강화 성공 확률 **+10%p** | 상점·일일 보상 |
| **행운의 모루** | 3회 동안 성공 확률 +5%p | 업적 보상 |

## 3. 도파민 요소 【제안】

원칙: **결과를 알기 직전의 0.5초를 가장 길고 화려하게** 만든다. 성공은 크게 터뜨리고, 실패는 짧고 가볍게 넘겨서 바로 다시 누르고 싶게 한다. 실패한 쪽의 화면을 너무 어둡게 만들지 않는다(좌절보다 "아깝다").

### 3.1 강화 한 번의 연출 (핵심)
1. **누르기**: 버튼을 누르면 대장장이가 망치를 든다. 길게 눌러 충전하는 방식도 가능(터치 기기에서 꾹 누르기, 카운트다운 게이지).
2. **긴장 0.6~1.2초**: 단계가 높을수록 길어진다. 화면이 어두워지고 검만 밝게, **심장 박동 소리·화면 가장자리 붉은 맥박**, 모루 불꽃이 점점 커진다.
3. **망치질**: 타격 순간 **히트스톱(0.08초 정지)** + 화면 흔들림.
4. **결과 공개**: 
   - 성공: 흰 번쩍임 → 검에서 빛줄기 → **숫자가 +n 으로 "펑" 커졌다 줄어듦** → 단계 색 변화 → 효과음 음정이 단계마다 한 칸씩 올라감.
   - 실패(유지·하락): 작은 "팅" 소리, 검이 한 번 흔들림, **"한 번만 더!"** 버튼이 자동으로 포커스됨.
   - 파괴: 검이 **조각으로 깨지며 흩어짐**, 잠깐 정적 → 검 조각 획득 연출로 바로 보상을 보여 줘 낙담을 줄임(3.4).
5. **니어미스**: 실패했을 때 확률 판정 막대가 "성공 칸 바로 옆"에 멈춘 모습을 보여 준다("아슬아슬!").

### 3.2 검의 시각 성장
- 단계마다 **검 외형·오라 색**이 바뀐다: +0~4 나무/철, +5~9 강철+푸른 빛, +10~14 금빛 오라, +15~19 보라 번개, +20 무지개 불꽃 + 검 이름 변경("전설의 …").
- **이정표 연출(+5·+10·+15·+20)**: 전체 화면 컷인, 검이 회전하며 새 모습으로 변신, 대장장이 대사, 짧은 팡파르.
- 화면 배경도 단계에 따라 변한다(작은 대장간 → 용암 동굴 → 하늘 위 신전).

### 3.3 연속·확률 장치
- **연속 성공 콤보**: 연속 성공마다 "COMBO ×n" 표시, 3연속부터 불꽃 효과·골드 보너스(+5%×콤보).
- **대성공(2단계 점프)**: 성공의 3% 는 **+2 단계 상승**. 나오면 "대성공!!" 전체 화면 연출. 나올 가능성이 있다는 것 자체가 기대감을 만든다.
- **천장(피티)**: 연속 실패 n회마다 다음 성공 확률 +3%p 누적(성공하면 초기화). 화면에 **"행운 게이지"** 로 쌓이는 것을 보여 줘 실패를 "충전"으로 느끼게 한다.
- **골든 타임**: 무작위로 60초 동안 "성공 확률 +10%p" 이벤트가 뜬다(알림음 + 검이 금빛). 지금 누르러 가게 만드는 장치.

### 3.4 파괴를 덜 아프게 하기
- 파괴 → **검 조각**(단계에 비례해 지급). 조각으로 **영구 강화**(시작 골드·방어권 확률·축복 효과) 구입. "죽어도 강해지는" 구조로 다시 도전 의욕을 유지.
- 파괴 직전 단계(+15 이상)에서 **"방어권을 쓸까요?"** 선택 창을 띄워 선택하는 긴장을 만든다.

### 3.5 수집·목표
- **검 도감**: 나무 → 철 → 강철 → 미스릴 → 용의 검 → 별의 검(검 종류 6개). 각 종류에서 +20 달성 시 다음 종류 해금, 도감에 이름과 그림이 채워진다.
- **업적**: "첫 파괴", "3연속 성공", "+10 달성", "방어권 없이 +15" 등. 달성 때 작은 연출과 보상.
- **일일 보너스**: 하루 첫 접속에 보너스 상자(방어권 1·축복 1 중 하나가 랜덤).

### 3.6 소리
- 모든 소리는 `WebAudio` 로 코드에서 만든다(파일 불필요). 단계가 오를수록 **강화음의 음높이가 올라가고**, 파괴는 낮은 유리 깨짐음. 소리 끄기 버튼 필수.

### 3.7 학교 수업에 맞춘 안전장치 【확인】
- 실제 돈·결제·가챠 구매 요소 **없음**. 모든 골드는 게임 안에서만 쓴다.
- **확률 공개**: 강화 버튼 위에 성공·유지·하락·파괴 확률을 항상 보여 준다(수학 "확률·기댓값" 단원과 연결).
- 연속 20분 이상 플레이하면 "잠깐 쉬어요" 작은 안내(강제 아님) 【확인】.
- 결과 화면에 **내 기대값**(오늘 강화 n회 중 성공 n회, 이론 확률과 비교)을 보여 줘 "실제 확률은 이렇다"를 배우게 한다.

## 4. 화면 구성 (저장소 규칙에 맞춤)
- **시작 화면**: 30·31번 방식(`st-*` 카드) — 제목 → `시작하기` 버튼 → 기록(`.st-recs`: 내 최고 단계·세계 신기록) → 조작 방법 → 규칙. 부제 문장 없음. 색은 대장간 분위기(`--st-bg` 어두운 갈색, `--st-accent` 주황 `#D97B4F`).
- **게임 화면**: 가운데 검과 모루(2D 캔버스 + DOM), 위쪽 `.hud-box`(골드·현재 단계·최고 단계·콤보), 아래쪽 강화/판매/아이템 버튼, 한쪽에 확률 표·행운 게이지.
- 2D 로 시작한다(3D 배경·캐릭터는 불필요, 기준 기기 부담 없음). 터치·마우스 모두 가능, 가로·세로 대응.
- 그리기 루프는 `requestAnimationFrame` 하나, 히트스톱·흔들림·파티클은 `transform`·`opacity` 위주.

## 5. 기록·계정 (저장소 공통 규칙)
- **최고 단계/최고 골드**를 `localStorage`(`swordforge_best_v1`)와 계정(`WorldRecord.syncBest`)에 저장.
- **세계 신기록 · 우리 반 신기록**: 기록 = "도달한 최고 단계" 로 시작, 동점이면 시간(적을수록 좋음)은 【확인】. 게임 키 `swordforge`, `데이터베이스규칙.json` 의 `.validate` 점수 상한 추가(선생님이 콘솔에 다시 게시해야 함).
- 개인전이므로 대전·랜덤 매칭·방 코드·계정 통계(내 통계 20매치)는 **만들지 않는다**. 필요하면 나중에 "누가 먼저 +20?" 경쟁 모드로 확장 【확인】.

## 8. 일정 제안
1. **M0** 규칙 엔진 + 확률표 + 시뮬레이션 → 선생님이 수치 확인 (연출 전에 먼저)

6. **M5** 기록(최고·세계·우리 반)·`초기데이터.json` 등록·`링크제목맞추기.ps1`·커밋·푸시

## 9. 선생님 확인 사항 【확인】
1. 확률표(2.1절)·비용·판매가 초기값 ★ 그대로 시험해 봐도 되는가?
2. 파괴 시 **검 조각으로 영구 강화**(3.4)를 넣을까? 넣으면 "죽어도 강해지는" 느낌, 빼면 더 단순·긴장 ★넣기
3. 세계 신기록 기준: ★최고 단계 (동점은 빠른 시간) / 누적 골드
4. 연속 플레이 안내(20분 "잠깐 쉬어요") 넣기 ★넣기
5. 나중에 대전("먼저 +20 달성") 모드를 붙일 생각이 있는가? 있다면 처음부터 규칙 엔진에 시드 공유를 넣어 둔다.
6. 검 종류 6개·이름은 ★위 3.5 그대로 / 직접 정하기
