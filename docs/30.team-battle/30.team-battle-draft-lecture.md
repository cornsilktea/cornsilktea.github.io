# 30번 팀 배틀 아레나 — 조합과 밴픽 강의안

대상: 학급 대표 선수와 응원하는 학생 전체. 분량: 50분 한 차시(활동 포함).
이 강의안은 게임 코드의 규칙(`docs/30.team-battle/30.team-battle-notes.md`)과 캐릭터 카드를 근거로 썼다.
수치는 패치로 바뀌므로, 수업 전에 캐릭터 카드(밴픽 화면의 설명)와 맞는지 한 번 확인한다.
"이 조합이 강하다"는 말은 규칙에서 따져 본 **이유**이지 승률 보장이 아니다. 수업 마지막 활동에서 직접 확인하게 한다.

---

## 0. 수업 목표

1. 밴픽이 "좋아하는 캐릭터 고르기"가 아니라 **3명이 한 팀으로 하는 문제 풀이**임을 안다.
2. 좋은 조합과 나쁜 조합을 **이유와 함께** 설명할 수 있다.
3. 연계(예: 점성술사 + 투척병, 군중제어 + 공격)를 한 문장으로 말할 수 있다.
4. 밴과 픽 순서에 따라 무엇을 고를지 정할 수 있다.

---

## 1. 도입 — 3대3이라는 조건 (5분)

- 한 팀은 **3명**이다. 3명이 "딜, 버티기, 군중제어(CC), 회복, 이동·시야"를 전부 맡을 수는 없다. 그래서 **한 캐릭터가 둘 이상을 맡거나, 빠진 부분을 약점으로 받아들이는** 선택을 해야 한다.
- 한 경기에서 **같은 캐릭터는 양 팀 합쳐 1명만** 고를 수 있다. 내가 고르면 상대는 못 고른다 → 픽은 "나에게 이득 + 상대에게 손해"다.
- 승패는 **킬 수**로 정해진다(시간이 끝나면 킬이 많은 팀, 같으면 연장전에서 먼저 처치한 팀). 점수는 결국 "누가 먼저, 많이 쓰러뜨리나"다.

**질문 던지기**: "세 명 모두 원거리 딜러면 어떻게 될까?" → 학생 답을 칠판에 적어 둔다. 마지막에 다시 꺼낸다.

## 2. 캐릭터를 읽는 법 — 역할 4군과 5가지 질문 (10분)

### 2-1. 역할 4군

| 역할 | 하는 일 | 캐릭터 |
|---|---|---|
| 전사 | 앞에서 버티고 길을 연다 | 광전사, 기사, 대장장이, 수문장, 창술사, 거신, 사슬 망령, 선봉장 |
| 마법사 | 넓은 범위·회복·군중제어 | 화염술사, 네크로, 클레릭, 드루이드, 점성술사, 마리나, 얼음술사 |
| 원거리 딜러 | 멀리서 꾸준히 피해 | 궁수, 저격수, 투척병, 주술사, 뇌전사수, 공학자 |
| 암살자 | 빠르게 파고들어 하나를 잡는다 | 결투가, 은신자, 자객, 검무희 |

체력 감각: 전사는 대략 400 안팎(광전사 260, 거신 500), 마법사·딜러·암살자는 100~140 수준이다. **앞줄 하나가 있으면 뒤의 둘이 살아남는 시간이 크게 늘어난다.**

### 2-2. 캐릭터를 볼 때 던지는 5가지 질문

1. **얼마나 오래 버티는가?** (체력, 피해 감소, 은신, 회복)
2. **어디까지 닿는가?** (사거리, 돌진, 순간이동, 끌어오기)
3. **상대를 멈추게 하는가?** (기절·둔화·끌어당김·밀치기 = CC)
4. **한 번에 몇 명에게 닿는가?** (단일 / 광역)
5. **혼자 완성되는가, 짝이 필요한가?** (짝이 필요하면 연계 후보)

> 팁: 밴픽 화면에서 캐릭터를 누르면 나오는 **패시브·스킬 설명**을 이 다섯 질문으로 읽는 연습을 시킨다.

### 2-3. 스킬 게이지도 자원이다

스킬은 쿨타임이 아니라 **게이지**로 찬다. 기본 공격이 적에게 맞으면 오르는 캐릭터가 많고(역할마다 오르는 양이 다름), 클레릭처럼 "아군을 얼마나 회복했나"로 차는 캐릭터, 사슬 망령·드루이드처럼 **시간·위치로 차는** 캐릭터도 있다. 스킬이 도는 동안은 게이지가 오르지 않는다. → "스킬을 빨리 쓰는 팀"이 아니라 **"스킬을 적중시켜 게이지를 계속 채우는 팀"**이 이긴다.

## 3. 좋은 조합의 5가지 원칙 (10분)

### 원칙 1. 앞줄이 있는가 (보호)

뒤에서 쏘는 캐릭터는 체력이 100~120이라 한두 번의 스킬에 쓰러진다. 앞줄이 길목을 막아 주면 그 사이 딜이 들어간다.

- 기사: 방어태세로 받는 피해를 크게 줄이고, 끝날 때 주변 적을 기절시킨다.
- 수문장: 기본 공격에 맞은 적이 느려지고, 스킬로 주변 적을 밀어낸다 → **적이 뒷줄에 못 오게** 한다.
- 창술사: 처음 한 번 맞는 피해를 막는 보호막으로 시작한다.
- 선봉장: 아군 전체 이동속도 증가와, 스킬로 피해 감소·주는 피해 증가를 동시에 준다.

### 원칙 2. 군중제어(CC)와 피해가 이어지는가 (연계)

**CC는 피해를 "확정"으로 바꿔 주는 도구**다. 맞으면 피할 수 없는 시간이 생긴다.

- 기절하면 움직이지도, 스킬을 쓰지도 못한다(준비 동작이 있는 스킬은 **취소**까지 된다: 창술사 꿰뚫기, 궁수 난사, 클레릭 요한계시록, 검무희 칼날 폭풍).
- 둔화는 도망과 접근을 막는다. 3중첩 기절(얼음술사)처럼 쌓이는 CC도 있다.
- 끌어당김·밀치기는 **상대의 위치를 내 맘대로** 바꾼다.

좋은 팀은 CC가 **나오는 순간 다른 한 명이 이미 때릴 준비**를 하고 있다.

### 원칙 3. 서로의 약점을 덮는가 (보완)

- 사거리 짧은 딜러 + 적을 붙잡는 캐릭터
- 터지기 쉬운 딜러 + 앞줄 / 회복
- 광역 피해 + 적을 한곳에 모으는 캐릭터

### 원칙 4. 상대가 대처할 방법이 많지 않은가 (다양성)

딜은 세 가지 이상(근접·원거리·광역·스킬 중심)이 섞여야 한다. 한 가지 방식으로만 싸우면 **그 방식을 막는 캐릭터 하나**에 팀 전체가 막힌다.

### 원칙 5. 한 명이 쓰러져도 굴러가는가 (안정)

팀 전체가 한 사람의 스킬 하나에 의존하면, 그 한 명이 쓰러지거나 CC에 걸리는 순간 끝이다. 쓰러졌다 돌아오는 사이에도 싸울 수 있는지 본다.

## 4. 안 좋은 조합 — 이유와 함께 (5분)

| 안 좋은 조합 | 왜 안 좋은가 |
|---|---|
| **앞줄 없이 전원 후열(마법사·딜러)** | 체력이 낮아 암살자나 광역 스킬 한 번에 연달아 쓰러진다. 앞줄이 없어서 시간을 벌 곳이 없다. |
| **전원 근접** | 사거리 밖에서 쏘는 상대에게 접근하는 동안 맞기만 한다. 물·벽이 있는 맵에서 특히 손해다. |
| **CC가 하나도 없음** | 상대가 움직임을 마음대로 한다. 암살자나 이동 빠른 상대를 못 잡는다. |
| **딜이 하나도 없음**(전사·회복만) | 버티기만 하고 킬이 안 난다. 킬이 점수이므로 시간이 끝나면 진다. |
| **같은 종류의 스킬 중복** | 한 가지 대처법으로 전부 막힌다. 예: 전원 "기절이 필요한" 조합이 서로 기절을 못 걸면 의미가 없다. |
| **회복에 기대는 조합** | 상대가 화염술사 화상·투척병 중독을 쓰면 **회복이 50% 줄어든다.** 회복 캐릭터 두 명이 있어도 효과가 반으로 떨어진다. |
| **혼자만 완성되는 캐릭터 셋** | 연계가 없어서 세 명이 따로 싸운다. 개인 실력 차이만 남는다. |
| **카운터 하나에 통째로 막힘** | 예를 들어 클레릭 요한계시록은 기절·끌려감에 취소된다. 상대가 끌기·기절이 많으면 제 몫을 못 한다. |

**칠판 활동**: 도입의 "전원 원거리 딜러" 답과 위 표를 연결한다.

## 5. 연계 모음 — 이렇게 모이면 좋다 (10분)

> 아래는 코드의 규칙을 근거로 한 **연계의 이유**다. 수치는 카드와 맞는지 확인한다.

### 5-1. 점성술사 + 투척병 — "모으고 깔아라"

- 점성술사 스킬(블랙홀)은 반경 안의 적을 **약 3초 동안 중심으로 끌어당기고**, 끝날 때 폭발한다.
- 투척병의 독병·독안개는 **장판 위에 서 있는 적**에게 피해를 준다. 독안개는 적을 둔화시키고, 독병·독안개에 맞은 적은 **중독(4초, 회복 50% 감소)**에 걸린다. 독병(기본 공격)과 독안개(스킬) 피해는 **서로 겹쳐서 둘 다 들어간다.**
- 적이 한곳에 모이면 장판이 맞는 수가 늘고, 중독으로 상대 클레릭·마리나의 회복도 막힌다.
- 점성술사 기본 공격(별똥별)은 몇 번째마다 맞은 적을 기절시켜 **장판 위에 붙잡아 둔다.**
- 약점: 둘 다 체력 100대로 얇다. **앞줄 하나**를 세 번째 자리에 두는 것이 정석이다(예: 기사·수문장).

### 5-2. CC → 확정 스킬

| 앞 연계(CC) | 뒤 연계(공격) | 이유 |
|---|---|---|
| 사슬 망령 갈고리(끌려오는 동안 + 0.5초 기절) | 창술사 꿰뚫기 / 화염술사 메테오 / 아무 딜러 | 끌려와 기절한 적은 피할 수 없고, 아군 쪽으로 끌려오므로 모인 곳에서 맞는다. |
| 점성술사 블랙홀 | 화염술사 메테오 / 투척병 독안개 | 한곳에 모인 적에게 광역 스킬이 전부 맞는다. 메테오는 피해와 기절까지 있다. |
| 대장장이 내려찍기·기본 공격 기절 | 근접 딜러 / 뇌전사수 / 저격수 | 기절 시간 안에 조준이 거의 필요 없다. |
| 수문장 밀치기(둔화) | 궁수·저격수 | 밀려난 상대가 거리를 다시 좁히는 동안 쏘기만 하면 된다. |
| 얼음술사 둔화 중첩 | 무엇이든 | 3중첩이면 기절 + 최대 체력 비례 피해. 중첩을 다른 딜러가 이어서 쌓게 하면 빨리 닿는다. |
| 주술사 영역전개 기절 | 근접 암살자 | 영역이 커질 때 닿은 적은 기절한다. 그 사이 파고든다. |
| 마리나 해일(밀어냄 + 기절) | 뒤따라 오는 근접 | 일렬로 서 있는 적을 한 번에 기절시킨다. |

### 5-3. 지속전 연계

- **선봉장 + 네크로**: 선봉장 반경 안의 해골 병사는 이동속도·피해 증가·피해 감소를 받는다(해골이 금빛으로 빛난다). 해골 여러 마리가 강해진다.
- **선봉장 + 광전사**: 선봉장 스킬의 "주는 피해 증가"가 광전사 광폭화와 **합쳐서** 더해진다.
- **공학자 + 기사/수문장**: 포탑은 설치 후 약 12초 가만히 사격한다. 앞줄이 길목을 막고 포탑이 계속 쏘는 "진지전"이 된다. 포탑 옆에 서 있으면 이동속도도 오른다.
- **드루이드 + 은신 활용**: 드루이드 부쉬 안은 풀숲처럼 **밖에서 안이 안 보인다.** 안에서 아군이 회복받으며 기습할 수 있다. 얼음술사 눈보라도 안의 아군을 숨겨 준다.
- **클레릭·마리나 + 앞줄**: 회복은 앞줄이 길게 살아 있을 때 가장 효율적이다.

### 5-4. 연계를 깨는 법 (카운터)

| 상대 캐릭터 | 막는 상대 |
|---|---|
| 클레릭 요한계시록(제자리 기도, 기절·끌어당김에 취소) | 사슬 망령, 점성술사, 기절 스킬 |
| 검무희 칼날 폭풍(기절·넉백에 끊김) | 수문장 밀치기, 마리나 해일, 대장장이 |
| 창술사 꿰뚫기 / 사슬 망령 사슬(준비 동작 뒤 직선) | 옆으로 움직이는 법을 아는 상대, 풀숲·벽 |
| 회복 의존 조합 | 화염술사(화상), 투척병(중독) |
| 뒷줄 딜러 위주 팀 | 암살자(결투가, 자객, 은신자) |
| 뭉쳐 있는 팀 | 점성술사 블랙홀, 화염술사 메테오, 마리나 해일 |

## 6. 밴픽 — 순서와 전략 (5분)

### 6-1. 규칙 복습

1. **밴**: 블루 1번 선수가 먼저 15초 안에 1개, 이어서 레드 1번 선수가 1개. 밴된 캐릭터는 이번 경기에서 **양 팀 모두** 못 쓴다.
2. **픽**: 블루 1 → 레드 1·2 → 블루 2·3 → 레드 3 순서.
3. 픽이 끝난 뒤, 준비 완료 전에 **같은 팀끼리 캐릭터를 바꿀 수 있다**(상대와는 불가).
4. 시간이 지나면 고민 중이던 캐릭터가 자동으로 결정된다 → **미리 정해 두고 들어가기**.

### 6-2. 밴 — 무엇을 막을까

밴은 "가장 강한 캐릭터"가 아니라 **"우리 조합이 가장 곤란해지는 캐릭터"**를 막는 일이다.

- 우리 팀의 핵심 연계를 깨는 캐릭터(예: 우리가 클레릭에 기대면 사슬 망령)
- 우리가 상대하기 가장 어려운 CC (끌어당김·광역 기절)
- 이전 경기에서 그 팀이 자주 쓰던 캐릭터(상대 팀 습관)

### 6-3. 픽 — 순서마다 다르게

| 순서 | 역할 | 무엇을 고르나 |
|---|---|---|
| 블루 1번 (첫 픽) | 선공 | 상대가 카운터하기 어려운 **범용적인** 캐릭터. 뼈대를 정한다. |
| 레드 1·2번 | 대응 | 블루 첫 픽을 보고 대처하면서, 연계 쌍을 한꺼번에 가져갈 수 있다. |
| 블루 2·3번 | 보완 | 앞줄·CC·회복 중 **빠진 것**을 채운다. |
| 레드 3번 (마지막 픽) | 마무리 | 남은 캐릭터 중 우리에게 필요한 것 + 상대 조합을 깨는 카운터. 정보가 가장 많다. |

핵심: **먼저 고르는 쪽은 정보가 적고, 나중에 고르는 쪽은 맞춤 대응이 쉽다.** 첫 픽은 유연하게, 마지막 픽은 구체적으로.

### 6-4. 맵도 본다

맵 이름(숲속·강·던전·언덕)이 밴픽 화면에 보인다. 맵을 누르면 그림이 뜬다. 벽이 많으면 직선 스킬이 막히고, 물이 있으면 걸어 건널 수 없는 곳이 있다. 맵 구조를 보고 사거리·이동 캐릭터를 판단한다.

### 6-5. 팀 안의 소통

- 1번 선수가 순서를 이끌지만 **결정은 합의**로 한다.
- "나는 이 캐릭터가 아니면 못 한다"는 선수가 있으면, 그 선수를 먼저 고르게 하고 나머지로 짠다.
- 교환 시간에 서로 바꾸는 것도 방법이다.

## 7. 활동 — 직접 짜 보기 (12분)

### 활동 A. 조합 진단표 (개인 3분)

주어진 조합 3개를 보고 아래를 채운다.

| 조합 | 앞줄 | CC | 딜 | 회복 | 가장 큰 약점 |
|---|---|---|---|---|---|
| 기사·점성술사·투척병 | | | | | |
| 창술사·사슬 망령·궁수 | | | | | |
| 화염술사·네크로·저격수 | | | | | |
| 클레릭·마리나·드루이드 | | | | | |
| 결투가·은신자·자객 | | | | | |

**선생님 해설 예시**
- 기사·점성술사·투척병: 앞줄(기사) + 모으기(블랙홀) + 장판 딜(독) → 균형이 좋다. 약점은 빠른 암살자.
- 창술사·사슬 망령·궁수: 앞줄 둘 + 딜러 하나 → 단단하지만 **광역·원거리 딜 부족**. 킬 속도가 느려 연장전에서 불리할 수 있다.
- 화염술사·네크로·저격수: 전원 후열 → **앞줄 없음**. 해골이 앞줄 역할을 하지만 약하다.
- 클레릭·마리나·드루이드: 회복만 셋. 딜이 부족하고, 중독·화상에 회복이 절반으로 줄어든다.
- 결투가·은신자·자객: 전원 암살자. 순간 화력은 크지만 체력이 낮아 광역 기절 한 번에 무너진다.

### 활동 B. 모의 밴픽 (팀 6명 → 3대3, 7분)

1. 반을 2팀으로 나눈다(블루/레드). 칠판에 캐릭터 카드(이름만) 붙이기.
2. 실제 순서대로 **밴 → 블루 1 → 레드 1·2 → 블루 2·3 → 레드 3**.
3. 각 단계에서 **이유를 한 문장**으로 말하게 한다. 예: "사슬 망령을 밴한 이유는 우리 클레릭을 취소시키기 때문이다."
4. 끝나면 두 조합을 3장의 원칙(앞줄·CC·보완·다양성·안정)으로 채점한다.

### 활동 C. 실제 확인 (남은 시간 또는 방과 후)

- 연습모드에서 5-2의 연계 한 쌍을 직접 해 본다(예: 점성술사 블랙홀 → 투척병 독안개).
- 사람 경기에서는 AI와 달리 **서로 피하고 합을 맞춘다.** 직접 해 보면 "이론이 맞는지"가 보인다.

## 8. 정리 — 칠판에 남길 한 장 (3분)

> **조합의 공식**
> 1. 앞줄이 있는가?
> 2. CC가 있고, 그 CC를 이어받아 때리는 사람이 있는가?
> 3. 서로의 약점을 덮는가?
> 4. 상대가 대처할 방법이 많지 않은가?
> 5. 한 명이 빠져도 굴러가는가?
>
> **밴픽의 공식**
> - 밴 = 우리가 가장 곤란한 캐릭터를 막는다.
> - 첫 픽 = 유연하게, 마지막 픽 = 구체적으로.
> - 이유를 한 문장으로 말하지 못하면 그 선택을 다시 생각한다.

**다시 처음 질문**: "전원 원거리 딜러면?" → 앞줄이 없고 CC가 부족하며, 한 번 접근당하면 무너진다. 그래서 "좋아 보이는 캐릭터 셋"이 좋은 팀은 아니다.

## 부록 A. 교사용 진행 팁

- **캐릭터 카드를 화면에 띄워 놓고** 설명한다. 이름만 말하면 학생이 스킬을 모른다.
- 시간이 부족하면 5-3과 6-4를 빼고, 활동 B를 줄인다.
- 학생이 "내 캐릭터가 최고"라고 하면 반박하지 말고 **"이 캐릭터가 지는 상황"**을 먼저 묻는다.
- 승률 이야기는 조심한다. 시뮬레이션은 AI 기준이라 사람 경기와 다르고, 패치로 수치가 바뀐다. "이 캐릭터가 세다"보다 "이 상황에서 이런 이유로 좋다"를 가르친다.
- 대회 전 마지막 연습에서는 **대회 규정집**(`30.team-battle-tournament-rules.md`)의 밴픽·교환 부분을 함께 읽는다.
