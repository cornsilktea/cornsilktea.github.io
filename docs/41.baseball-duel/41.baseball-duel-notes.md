HTML 은 스크립트를 **motion → field → drills → actors → park → lab** 순서로 불러온다(정적 상수 초기화 순서).

**동작 방식**: KayKit 클립은 `Idle_A`·`Running_A`·`Walking_A` 만 쓰고 나머지는 전부 절차 자세다. 자세는 "몸통 각도 + 손·발 목표점(+배트 위치)" 이고 `BbRigPoser` 가 뼈를 맞춘다. **두 손은 배트의 손잡이 점을 따라가므로 떨어지지 않는다**(배트는 손 뼈가 아니라 선수 기준 공간에 놓인다 — 사양서 0.2절의 `BatGrip` 손슬롯 부착 대신 이 방식을 썼다).
모든 동작은 `시작 = 사건 시각 − keyTime` 으로 예약한다(`BbActionSync.startFor`). 공은 손 뼈에 붙어 있다가 릴리스 시각에 그 위치에서 출발하고, 포구 시각에 글러브 뼈에 붙는다.

**캐릭터 비율**: KayKit 은 키 약 1.8m 에 머리 지름 약 0.9m, 어깨 높이 0.89m, 팔 0.54m, 다리 0.30m 다. 그래서 스트라이크 존은 중심 높이 0.62m·반높이 0.24m·반폭 0.25m 로 잡았고(`BbStrikeZoneBox`), 사양서 7.7절 카메라 값(투수 뒤 2.4m, 심판 위치 1.6m)은 머리에 가려 그대로 쓸 수 없다. 시험 페이지 값: 타자 시점은 포수·심판을 숨기고 홈 뒤 2.7m·높이 1.0m·시야각 30°, 투수 시점은 옆 1.9m·뒤 4.2m·높이 3.5m·시야각 26°. **M1 에서 선생님과 확정한다.**

## 3. 선생님 피드백 기록

**2026-11-12 1차 (M0a 시험 장면)** — 모두 반영
1. 배터박스 안으로 파울라인이 넘어옴 → 파울라인을 홈에서 1.72m 지점(박스 앞 모서리 밖)부터 그린다.
2. 외야 펜스 광고판 글씨 → 전부 없앰(패딩 무늬·노란 윗줄만).
3. 전광판 → 실제 모양(이닝 1~9·R·H·E 표, 원정/홈 두 줄, B·S·O 등). 지금은 고정 그림이고 실제 점수 연결은 M3 HUD 때.
4. 플라이 때 외야수 클로즈업 금지 → 넓은 추적 화면만.
5. 타격 시점 → 심판 위치, 포수·심판 숨김, 존이 화면 세로의 약 30%. 존 테두리 표시.
6. 공이 작음 → 보이는 반지름 0.045 → 0.07m(판정용 공 크기와 별개).
7. 포수 장비가 글러브와 겹침 → 가슴 보호대를 몸에 붙는 둥근 판으로, 미트는 몸 앞·옆으로 더 뺌. 심판 보호대는 없앰.
8. 조명에 쇠 기둥이 겹침 → 기둥을 조명판 아래에서 끝냄.
9. 폴대 쪽 거리 표시가 가려짐 → 100 표지를 ±41° 로 옮기고 벽 앞으로 띄움.
10. 송구를 서서 함 → 포구 0.4초 뒤부터 목표 쪽으로 걸어 나가며 던진다(내야 1.1m, 외야 크로우 홉 2.2m).

**2026-11-13 2차** — 모두 반영: 투수 시점을 중계 화면 구도(중견수 쪽 뒤·위에서 망원)로, 타자 시점을 홈–투구판 일직선으로, 스트라이크 존 테두리는 투구·타격 때만, 타격 뒤 투수가 타구 방향으로 몸을 돌림.

## 5. 남은 일·알아 둘 것

- M0a 에서 아직 안 한 것: 유니폼 스타킹·스파이크 색 구분(캐릭터 텍스처 칸 규칙이 없어 벨트만 달았다), 구장 그림자 굽기는 벽·마운드 아래만, 불펜 없음, 관중은 정지 상태(움직임은 M7), 달리기 팔 흔들기 보정은 몸 기울임만.
- 팔을 어깨에 너무 가깝게 접는 자세(어깨에서 약 15cm 안)는 IK 가 못 맞춘다. 스윙 팔로스루는 고쳤고, 송구 자세는 눈으로 문제없어 그대로 두었다. 검사 도구에는 아직 이 한도가 없다.
- 사양서와 다르게 한 것: 클래스 이름 `Bb` 접두사, 배트 부착 방식(2절), 카메라 값(2절).
